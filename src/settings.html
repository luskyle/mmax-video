连接方式与能力边界

      
桌面应用直接使用本地 CLI，不需要 HTTP 服务。部署项目另外提供 HTTP API 和 MCP；其监听地址、鉴权和启动由各自客户端管理，本页不会自动开放网络端口。

      
首帧、尾帧输入目前通过部署 CLI／HTTP API 使用，创作页暂未提供图片选择。无声选项只在导出时移除音轨。工作区必须位于部署目录之外；旧工作区、视频和历史参数不会因切换预设而改写。
