# MMax Video Studio v1.0.1

增加 Debian / Ubuntu Linux x64 安装包，保留原有免安装压缩包。

## 下载与安装

从 Assets 下载 `mmax-video-studio_1.0.1_amd64.deb` 和 `SHA256SUMS`，放在同一目录：

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./mmax-video-studio_1.0.1_amd64.deb
mmax-video-studio
```

卸载：`sudo apt remove mmax-video-studio`。工作区和用户配置不会被删除。
deb 不创建应用菜单图标；应用通过 `mmax-video-studio` 命令启动。
如果不需要安装，也可以下载 `mmax-video-studio-1.0.1-linux-x64.tar.gz`，验证校验和后解压运行。

## 运行条件

- Linux x64 图形桌面，推荐 Ubuntu 22.04 或更新版本；需要 Electron 所需系统库。
- 本地 MiniMax H3、模型、CUDA 和 FFmpeg 需另行部署，不包含在安装包中。
- 应用含 Electron 运行时，无需另装 Node.js；无声模式只在导出时移除音轨。
- 画布布局与视角只在当前工作区会话中保留；删除创作记录会同时删除对应文件。

## 验证

CI 构建两种格式并校验 SHA-256；在隔离目录中安装 deb，启动打包后的应用进行画布和设置冒烟测试，再验证卸载。
自动化测试不运行 GPU 推理。
